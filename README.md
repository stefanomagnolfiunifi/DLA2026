# DLA2026

This repository contains the practical laboratory assignments for the Deep Learning Application course (DLA 2026). The laboratories selected are: 
- #1 From Pixels to Semantics
- #2 The Transformative Transformer
- #4 OOD Detection and Adversarial Robustness

Environment and dependency management are entirely handled using [uv](https://github.com/astral-sh/uv).

## Environment Setup

To get started with the notebooks and scripts, simply clone the repository and use `uv` to synchronize the environment.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/stefanomagnolfiunifi/DLA2026.git
   cd DLA2026
   ```

2. **Create the environment and install dependencies:**
   Make sure you have `uv` installed on your system. Then, run:
   ```bash
   uv sync
   ```
   This command will automatically create a virtual environment and install all the required packages listed in the project dependencies.

## Repository Structure

The repository is organized into three main laboratory sessions. Each lab features an interactive Jupyter Notebook (`.ipynb`) accompanied by supporting Python files to keep the notebooks clean and modular.

### 1. ResNet Lab
* **`*.ipynb`**: Main notebook containing the core experiments and training loops.
* **`library.py`**: A supporting module that houses custom helper functions, utilities, and classes utilized throughout the notebook.

### 2. Transformers Lab
* **`*.ipynb`**: Main notebook for experimentation and model implementation.
* **`retrieval.py`**: A standalone **Gradio** web application that allows you to visually and interactively test the retrieval system developed in this lab.

### 3. Adversarial Lab
* **`*.ipynb`**: Main notebook demonstrating adversarial attack and defense pipelines.
* **`library.py`**: A supporting file implementing the mathematical functions and adversarial example generation logic used in the notebook.

## How to Use

### Running the Notebooks
After executing `uv sync`, you can open and run the notebooks directly inside your preferred IDE (such as VS Code). Simply ensure that you select the Python kernel generated by `uv` (typically located within the local `.venv` directory).

Alternatively, you can launch Jupyter Notebook directly from your terminal:
```bash
uv run jupyter notebook
```

### Launching the Gradio Web App
To start the interactive web interface for the Transformers laboratory, run the `transformers_lab/retrieval_app.py` script using your IDE or `uv`:
```bash
uv run python transformers_lab/retrieval_app.py
```
Once executed, the terminal will provide a local URL (usually `http://127.0.0.1:7860/`) that you can open in any web browser to interact with the application.
